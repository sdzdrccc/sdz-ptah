# design/verify — 验证与基准实验记录

本目录放的是「阈值怎么定出来的」实验记录：原图、成品、评分报告与 manifest。

## 图片不入库

`raw/`、`control/`、`out-*/` 下的图片**都不进仓库**（见根目录 `.gitignore`），只有本地有。
原因见根目录 `README.md` 的「免责声明」：这些是既有版权角色的衍生形象，
公开仓库分发会触及原权利人的复制权与改编权，与是否商用无关。

因此：

- 各目录 `manifest.json` / `report.md` 里的图片路径是**本地历史记录**，克隆后没有对应文件；
- 想复现这些实验，需要自己准备参考图并重跑 `avatar_pipeline.py`，命令与参数都记在各自的
  `manifest.json` 的 `meta` 与 `runs` 里；
- 图片体积大（单轮约 35 MB）也是不入库的次要原因。

## 目录约定

| 目录 | 内容 |
|---|---|
| `raw/` | 待评分的原图（生成后端直接产出） |
| `control/` | 对照组（合成图、无脸图等），用于确认闸门不误判 |
| `out-*/` | 流水线输出：成品、联系表、`manifest.json`、`report.md` |
| `diagnostics/` | 一次性诊断脚本（连通域、边界等），只读，不改业务代码 |
